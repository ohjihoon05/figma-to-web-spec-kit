# Command Templates

## Primary Command Template

### Standard Figma-to-Web Conversion
```
Figma URL: [INSERT_FIGMA_URL_HERE]

Convert this Figma design to a complete web implementation with the following specifications:

**Output Requirements:**
- Single HTML file with inline CSS and JavaScript
- Use Figma asset URLs directly (no local downloads)
- Implement with Tailwind CSS + custom styles
- Container max-width: 1440px, centered with mx-auto

**Design Implementation:**
- 100% visual fidelity to Figma design
- Glassmorphism effects (backdrop-filter, transparency)
- Gradient backgrounds and animations
- Micro-interactions and hover states
- 2024-2025 design trends

**Animations & Interactions:**
- Scroll-triggered animations (fade-in, scale-in)
- Smooth transitions (0.3s cubic-bezier)
- Interactive elements (buttons, forms, carousels)
- Intersection Observer for performance

**Technical Standards:**
- Semantic HTML5 structure
- WCAG 2.1 AA accessibility
- Mobile-first responsive design
- Cross-browser compatibility
- Optimized performance (< 3s load time)

Please ensure all sections are included and no design elements are missing.
```
